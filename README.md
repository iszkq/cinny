# Cinny 中文定制版

基于 [Cinny](https://github.com/cinnyapp/cinny) 深度整理和扩展的 Matrix Web 客户端，当前仓库重点面向中文使用场景做持续完善，适合直接继续二开、补功能、做本地化和业务定制。

## 项目特点

- 更完整的中文界面，覆盖欢迎页、设置页、用户资料、房间资料、权限说明和大量细节提示。
- 修复并增强消息发送链路，降低“自己看到发送成功、对方却看不到”这类问题出现的概率。
- 保留并整合 AI 助手、消息收藏、圣经工具等扩展能力。
- 首屏与关于页已经改为本仓库定制信息，内置源码入口和作者联系弹窗。
- 代码结构依然保持 Cinny 原本的页面层、功能层、组件层分离方式，适合继续维护。

## 最近更新

1. 欢迎页改为中文首屏，并将源码地址统一到当前仓库。
2. “支持项目”入口改为“联系作者”，点击后弹出二维码和作者联系方式。
3. 关于页移除原致谢列表，替换为功能更新说明板块。
4. 进一步细化开发者工具、账号数据编辑器、房间事件编辑器等页面的中文文案。
5. 优化消息发送失败提示与重试链路，补强附件发送后的事件投递可靠性。

## 主要功能

### 基础聊天能力

- 支持 Matrix 账号登录、注册、SSO、密码重置。
- 支持房间、私聊、空间、探索页、收件箱等基础视图。
- 支持文本、图片、视频、音频、文件、贴纸等消息类型。
- 支持消息回复、转发、收藏、媒体预览和通话状态展示。

### 中文场景增强

- 大量界面文案已改为中文，减少英文混杂。
- 房间设置、空间设置、权限面板、用户资料卡等区域做了细化说明。
- 连接状态和异常状态提示更直观，便于定位同步与发送问题。

### 定制扩展功能

- 收藏系统：支持收藏消息、分类浏览、备注、筛选、批量管理。
- 圣经工具：支持经文检索、章节浏览、复制和插入消息输入框。
- AI 助手：保留现有智能辅助能力，方便继续扩展接入。

## 目录说明

- `src/app/pages`：页面入口与路由组织。
- `src/app/features`：按业务模块拆分的核心功能实现。
- `src/app/components`：通用 UI 组件、弹窗、编辑器、渲染器。
- `src/app/state`：应用状态管理。
- `src/app/hooks`：公共 hooks 与状态封装。
- `public/res`：静态资源，包括图标和作者联系二维码。

## 本地开发

安装依赖并启动开发环境：

```bash
npm ci
npm start
```

常用命令：

```bash
npm run build
npm run typecheck
npm run lint
```

## 部署说明

- 默认构建输出目录为 `dist/`。
- 支持 Docker / Nginx 等常见静态部署方式。
- 服务端和探索页相关配置可在 `config.json` 中调整。
- 子目录部署可结合 `build.config.ts` 进一步配置。
